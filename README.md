# Hotel Booking UI

A modern and responsive Hotel Booking UI built using React and CSS. This project provides a clean interface for users to search hotels, browse available accommodations, view hotel details, and make bookings through an intuitive booking form.

## Preview

The application includes:

- Navigation Bar
- Hotel Search Section
- Dashboard Statistics
- Hotel Listings
- Hotel Cards with Ratings and Pricing
- Booking Form
- Responsive Layout

## Features

### Hotel Search
- Search hotels by destination
- Select check-in and check-out dates
- Specify number of guests
- User-friendly search interface

### Dashboard Statistics
- Total Hotels
- Available Rooms
- Average Ratings

### Hotel Listings
- Display hotel information
- Hotel images
- Location details
- Pricing per night
- Ratings display
- Book Now button

### Booking Form
- Full Name input
- Email input
- Guest selection
- Room type selection
- Booking confirmation button

### Responsive Design
- Mobile-friendly layout
- Responsive hotel grid
- Adaptive navigation bar
- Flexible dashboard cards

- ## Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- CSS3

### Build Tool
- Vite

## Installation

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project Folder

```bash
cd hotel-booking-ui
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```
